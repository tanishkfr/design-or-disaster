# Dark Editorial Forensics — Phase 2.0

The user-selected direction replaces the old rounded archive UI. The cover is an experimental publication; investigation surfaces are precise working instruments. Preserve the same evidence coordinates across both.

## Foundations
Background #0B0D10; surface #181B20; raised #282B31; paper text #F3F1EB; signal #FF634D. Secondary text #B5B8BE and muted #979CA5 remain readable. Signal indicates interaction, not a verdict. Lens and verdict colors retain independent semantic roles.

Archivo is the primary display/interface family. Instrument Serif italic provides selective editorial contrast. IBM Plex Mono carries case identifiers and evidence metadata. Display headings use tight, deliberate lines; body copy stays readable at 14–18px.

## Composition
48px desktop / 20px mobile outer gutters. Cover title dominates the first viewport; a slash divides observation from interpretation in a real exhibit. Index uses numbered rows with a sticky selected preview. Workbench uses an exhibit plus a narrow inspector, stacking into an explicit observe-then-rule sequence on compact screens. Reports use long-form editorial spacing.

Thin rules establish structure. Square controls, open surfaces, restrained borders; no glow, gradients or repeated card grids. Controls have visible focus and 44px touch targets.

## Interaction
Split: pointer-controlled clipped evidence layer plus native range control.
Instrument: point or rectangle mode, percentage coordinates, editable observations and geometry, removable marks and named-region alternatives.
Reveal: range-controlled clipping of visitor versus selected authored annotations on one image. Sealed cases expose no external layer.

## Motion
Short 140–200ms control feedback; 280ms navigation entrance. Marker placement is immediate. No cursor outside the exhibit. Reduced motion removes transitions and timed introductions. Tools never wait for animation.

## Persistence boundary
Keep design-eye-profile and existing point marks. Optional width/height fields extend marks without changing x/y semantics: points are centered at x/y; rectangles start at x/y. Never remap old coordinates.


## Phase 2.1 extension

Retain these foundations. Investigation stages use one persistent numbered rail and an exhibit-first workspace. Context documents unfold beside the preserved first map; provenance sits with each document. Explore and Mark are explicit square mode controls. Live exhibits can contrast with the dark host, but are always labeled as reconstructions.

A captured exhibit retains its logical dimensions and is scaled as a whole for accurate annotations. Reflection uses paired editorial decisions and separately labeled exhibit states. Do not place a comparison divider over incompatible geometry. Optional classification starts unselected; do not prime the first look with five lens buttons. Completed judgments and historic attempts are visually read-only.

## Phase 2.2 collection and document extension

The index leads with five numbered, open editorial rows; the original archive stays in a labeled disclosure. Keep the host's near-black, paper, signal, typography and square instruments. Each working exhibit has its own purpose-built visual language: restrained blue finance, public-service form, lilac expressive portfolio, dense serif noticeboard and blunt garment storefront. Native controls and optional finite motion remain operable on touch and keyboard.

Perspective layers compare one explicitly selected source state. Source-image geometry and live reconstruction geometry remain separate. A missing authored region produces a plain availability statement, never a fabricated rectangle. Curated contradictions name the shared element, conflicting readings and uncertainty.

Design Eye is an editorial document: oversized title, open ruled counts, case timelines, actual evidence states and quoted reasons. Avoid personality or proficiency labels. PNG uses the same paper/signal/dark hierarchy with two-column judgment excerpts and explicit evidence-selection disclosure. Print switches to white paper, retains actual colors inside exhibits, scales each capture as a whole and starts second looks on deliberate pages. Keep text and evidence together; inspect actual output after print changes.

## Phase 2.3 corrective refinements

Keep case identity visible during observation and distinguish Explore from frozen Mark. Observations wrap; focus returns to a surviving note or the instrument after removal. Point permits vertical touch scrolling; Region reserves dragging. In-page focus links must preserve hash routes.

Cover annotation geometry belongs to the image plane. Shared authored regions use one boundary and reading numbers matched to their text; labels sit at the right edge so the revealed authored side can expose them. Both layers remain named above the comparison. Do not add movement to precision input.

Navigation uses a short opacity exit for pointer input, immediate switching for keyboard/reduced motion, and the existing brief entrance. Marker registration is small and immediate. Reduced motion still removes animation.

Print uses layout-aware zoom where supported to prevent pre-transform pagination from clipping tall frozen captures. Preserve their logical dimensions and percentage geometry. Inspect lower exhibit content in the actual PDF, not only saved notes or matching container widths.
